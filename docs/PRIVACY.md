# ScamShield Privacy

## Privacy by Design

ScamShield should collect only the information necessary to provide scam detection, evidence organization, security, and reporting assistance.

## User Data

Potentially sensitive information may include:

- Messages and communications
- Email addresses
- Phone numbers
- Social-media identifiers
- Website addresses
- Cryptocurrency addresses
- Transaction identifiers
- Screenshots and uploaded evidence

## Data Minimization

ScamShield should avoid collecting information that is not necessary for the requested service.

## Evidence

Users should understand what information is being stored and why.

Evidence should be protected from unauthorized access and modification.

## User Control

Users should have appropriate control over their submitted information, subject to legitimate security, legal, and reporting requirements.

## Third-Party Services

External services should receive only the information necessary for the specific function being performed.

Secrets and API credentials must never be stored in the application source code.

## Privacy and Reporting

ScamShield should clearly distinguish between information supplied by the user, information detected by the system, and analytical conclusions.

The application should not publicly expose private information about alleged scammers or victims.
