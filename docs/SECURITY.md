# ScamShield Security

## Security Goals

ScamShield must protect users, evidence, accounts, and the integrity of scam reports.

## Principles

- Never store passwords or secrets in source code.
- Never expose API keys or private credentials.
- Minimize collection of personal information.
- Protect evidence from unauthorized modification.
- Validate and sanitize user input.
- Use authentication and authorization where required.
- Log security events without unnecessarily logging sensitive information.
- Rate-limit public endpoints.
- Protect reporting and analysis services from abuse.

## Evidence Security

Evidence should be handled carefully and should retain relevant metadata and integrity information.

## Responsible Disclosure

Security vulnerabilities should be reported privately to the project maintainers rather than publicly exposing an exploitable weakness.
